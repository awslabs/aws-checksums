# aws-checksums
Cross-Platform HW accelerated CRC32c, CRC32, and CRC64 (NVME polynomial) with fallback to efficient SW implementations. C interface with language bindings for each of our SDKs 

## Versioning

This library uses a three-part `Major.Minor.Patch` version scheme. See
[VERSIONING.md](VERSIONING.md) for what each part means and our API/ABI
stability policy.
